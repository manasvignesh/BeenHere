### Step 3: Subprocess Network Execution & Sandbox Socket Restriction
Codex attempted to execute the GitHub search script:

```bash
python .agents/skills/beenhere/scripts/github_search.py \
  --queries "recruitment ats" "resume parser" "job matching" \
  --output research/recruitment-script-network-errors.json \
  --json
```

**Observed Result & Root Cause Analysis:**
- Exit code: `2` (handled error exit)
- Generated diagnostic log: `research/recruitment-script-network-errors.json`
- **Error Content:**
  ```text
  Query 'recruitment ats' failed: Network error accessing GitHub API: [WinError 10013] An attempt was made to access a socket in a way forbidden by its access permissions
  ```
- **Root Cause:** In Codex's Windows environment, subprocess child processes spawned by the agent runner do not have raw outbound socket creation privileges (`[WinError 10013]` / `WSAEACCES`), preventing Python's `urllib.request` from opening direct TCP sockets.

## 4. Key Technical & Legal Discoveries

The Codex run demonstrated high-fidelity technical intelligence:

1. **PyMuPDF Dual-Licensing Hazard in Horilla-HR:**
   - Horilla HR ([horilla/horilla-hr](https://github.com/horilla/horilla-hr)) is licensed under LGPL-2.1. However, inspecting its `requirements.txt` revealed a mandatory dependency on `pymupdf`.
   - Codex flagged that PyMuPDF is dual-licensed under AGPL-3.0 and an Artifex commercial license. For a commercial SaaS product, embedding Horilla carries serious reciprocal copyleft risk unless commercially licensed or decoupled.
2. **Resolution of GitHub API `NOASSERTION` Licenses:**
   - [pgvector/pgvector](https://github.com/pgvector/pgvector): API returned `NOASSERTION`; inspecting raw `LICENSE` confirmed it is permissive PostgreSQL-style open source.
   - [opencats/OpenCATS](https://github.com/opencats/OpenCATS): API returned `NOASSERTION`; inspecting raw `LICENSE.md` revealed a mixed-license situation (MPL-2.0 and CATS Public License 1.1a).
3. **Core Building Blocks Identified:**
   - [docling-project/docling](https://github.com/docling-project/docling) (70k+ stars, MIT): Recommended for document conversion infrastructure (`DocumentConverter.convert`).
   - [huggingface/sentence-transformers](https://github.com/huggingface/sentence-transformers) (19k+ stars, Apache-2.0): Recommended for embeddings and `CrossEncoder.predict`/`rank`.
   - [fairlearn/fairlearn](https://github.com/fairlearn/fairlearn) (2.3k+ stars, MIT): Recommended for bias and group-level metric assessment (`MetricFrame.difference`/`ratio`).
